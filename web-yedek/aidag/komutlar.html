🩺 Sağlık & Durum

Tam sistem sağlık kontrolü
Node'lar, KUBRA, site, belge — hepsi ayakta mı.
echo "=== NODE ==="; systemctl is-active lsc-node.service aidag-mainnet.service guvenli-mod.service
echo "=== SENKRON ==="; curl -s -m5 http://127.0.0.1:8645/status | python3 -c "import sys,json; d=json.load(sys.stdin); print('vertex='+str(d.get('vertex_count','?')),'tip='+str(d.get('tip_count','?')),'orphan='+str(d.get('orphan_count','?')))"
echo "=== KUBRA ==="; curl -s -m5 http://127.0.0.1:8646/health && echo ""
echo "=== SITE ==="; curl -s -m8 -o /dev/null -w "site %{http_code}\n" https://aidag-chain.com/
echo "=== BELGE ==="; curl -s -m8 -o /dev/null -w "belge %{http_code}\n" https://aidag-chain.com/belge

🧠 KUBRA Testleri

KUBRA cevap veriyor mu
Basit soru + model bilgisi.
curl -s -m60 http://127.0.0.1:8646/v1/ask -X POST -H "Content-Type: application/json" -d '{"prompt":"Merhaba","deterministic":true}' | python3 -c "import sys,json; d=json.load(sys.stdin); print('CEVAP:',d.get('answer','')[:200]); print('model:',d.get('model'))"
Streaming test (harf harf)
Token token akış. -N = buffersiz.
curl -s -N -m60 http://127.0.0.1:8646/v1/ask-stream -X POST -H "Content-Type: application/json" -d '{"prompt":"AIDAG-Chain nedir? Kisaca.","deterministic":true}' | head -30
Beyin (llama-server) sağlıklı mı
Beyin ayakta mı, hangi model.
curl -s -m5 http://127.0.0.1:18650/health && echo ""
ps aux | grep llama-server | grep -v grep | grep -oE "\-m [^ ]+"
